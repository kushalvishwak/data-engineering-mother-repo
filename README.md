## Attribution and license boundary

All 20 repositories are stored as ordinary files in this repository, not as submodules. The seven repositories with detected licenses retain their upstream notices. For the other 13, the owner of this repository reports having obtained redistribution permission from their respective owners; that permission is not a public license and should not be assumed to extend to other people or uses. See [SOURCES.md](SOURCES.md).

The 119 MB source CSV exceeds GitHub's per-file regular-Git limit, so it is stored with Git LFS. After cloning, install Git LFS and fetch the file:

```powershell
git lfs install
git lfs pull
```
